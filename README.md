## About Me:

Hey, I'm **Aniket Sahu**, an engineering student at **MIT Manipal**.

### Interests:

- **Machine Learning & Data Apps**: turning raw data into models and dashboards people can actually use.
- **Full-Stack Development**: React front ends on Flask/Node back ends, backed by SQL databases.
- **Security & Networking**: network scanning, anomaly detection, and a lot of time in `nmap`.

### Work:

- **Hackathons**: Built **[Tributary](https://github.com/aniketsahu28m/tributary)** for the **OneAquaHealth IEEE Global Hackathon 2026**. It triages citizen stream observations into sampling priorities and publishes them as FHIR resources.
- **Applied ML**: Shipped **[SmartCrop](https://smartcrops.streamlit.app)** (99.3% hold-out accuracy) and **[Optomarket](https://optomarket.streamlit.app)**, both live on Streamlit.
- **Systems Coursework**: OS, networking, embedded systems, and data structures labs in C and Assembly.

### Contributions:
